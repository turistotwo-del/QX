# QX Подборщик 4.0.26 — автоматическая установка QX AI

Основа — версия 4.0.25 с несколькими ТЗ, тендерами, расчётами и проверкой AI-цитат.

## Новое

- **Автоматическая первоначальная настройка QX AI** при первом portable-запуске или на шаге установки Windows EXE через Inno Setup.
- Используется официальный Windows CLI Ollama v0.40.4 с фиксированным SHA-256, загружаемый по HTTPS, и **Qwen3 4B Instruct** (~2,5 ГБ, Apache 2.0).
- Уже работающая Ollama используется повторно, её процесс не завершается и сторонняя установка не переписывается.
- QX хранит собственный AI-движок и модели в `%LOCALAPPDATA%\QXPodborshchik\QX_AI` отдельно от приложения, данных закупок и прайсов.
- На Windows движок стартует вместе с QX и закрывается при выходе, если QX запустил его самостоятельно.
- При отсутствии интернета, нехватке места или иной ошибке QX продолжает обычную работу, пишет диагностику и предоставляет повторную установку через `УСТАНОВИТЬ_QX_AI.cmd`.
- Вкладка ТЗ по умолчанию выбирает найденную Qwen3 4B Instruct. Автоматическое применение исправлений по-прежнему запрещено: оператор подтверждает предложенные исправления и цитаты.

## Установка и ограничения

Первый запуск требует интернет, ~7 ГБ свободного места на диске для развёртывания, и загрузку ~1,4 ГБ движка плюс ~2,5 ГБ модели. Когда системная Ollama уже установлена, 1,4 ГБ повторно не скачиваются. Установку не следует прерывать во время загрузки.

В ZIP **не включены** Ollama и модель: они скачиваются и устанавливаются автоматически на компьютере пользователя, а не под видом заранее встроенной нейросети. При обычном запуске после настройки QX AI работает локально и без интернета.

Windows EXE нельзя собрать или проверить без Windows + PyInstaller/Inno Setup. Текущий ZIP — тестовый portable-кандидат; `windows_build/QX_Setup.iss` подготовлен для автоустановки AI в интерактивном установщике. Установка пропускается при полностью тихой установке, чтобы не запускать многогигабайтную сетевую загрузку без интерфейса.

Модель не гарантирует юридическую или техническую корректность определения требований: всегда проверяйте цитаты и характеристики до подачи заявки. Сканированные PDF без текстового слоя требуют OCR.
