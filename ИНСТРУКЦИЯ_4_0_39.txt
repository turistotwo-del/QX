QX Подборщик 4.0.39 DEV — закупка по номеру и новый рабочий стол

ОБНОВЛЕНИЕ С 4.0.38
1. Закройте QX. Сохраните резервную копию программы и через меню QX — копию тендерной базы.
2. Для ZIP обновления скопируйте содержимое ОБНОВЛЕНИЕ_В_ПАПКУ_QX в существующую папку QX с заменой файлов.
   Для полного Portable распакуйте архив в отдельную папку.
3. Не удаляйте .qx_runtime, QX_UserData и данные QX в LocalAppData.
4. Запускайте ЗАПУСТИТЬ_QX.cmd. При первом запуске Portable необходим интернет для Python и библиотек;
   для фирменного окна нужен Microsoft Edge WebView2 Runtime.

КАК РАБОТАТЬ
На главной введите номер извещения (11, 19 или 20 цифр) и нажмите Enter / «Найти закупку».
Флажок загрузки документов включён по умолчанию. Можно отключить его и получить только сведения.
Карточка создаётся в локальном реестре; повторный поиск использует существующую карточку этого номера.
Подтверждённые сведения из XML или подписанных полей страницы ЕИС дополняют пустые поля.
Ручные значения не заменяются. Расхождения и отсутствующие сведения перечислены в отчёте.
Если номер уже есть в нескольких карточках, откройте нужную карточку и получайте данные из неё.

Из карточки: «Получить данные и документы» повторяет поиск; раздел «Документы» содержит сохранённые файлы.
Для подходящего файла нажмите «В расчёт как ТЗ»: QX разберёт его существующим движком.
Оригиналы DOC, XLS, RTF сохраняются для ручного просмотра; автоматический разбор для них не выполняется.
Загрузка ТЗ, сборка, цены, проверка заявки и экспорт теперь находятся в раскрывающемся разделе слева
«Расчёт и документы». Главная показывает реальные закупки, предстоящие даты и текущий расчёт.

ОГРАНИЧЕНИЯ
Это публичный поиск ЕИС, без закрытого API, авторизации или обхода капчи. ЕИС может ограничивать доступ.
Поиск охватывает открытые ссылки на проверенных страницах. Полнота комплекта документов не гарантируется.
За одно действие проверяется до 4 страниц, до 40 найденных файлов; общий сетевой лимит загрузки — 120 МБ.
Для больших комплектов и неподдерживаемых форматов используйте ручное прикрепление доступных файлов / ZIP.
Недоступные или отклонённые файлы не выдаются за скачанные; успешные результаты сохраняются.
Если время извещения содержит явный часовой пояс, QX не переносит его как местное время без проверки.
Статус победы, цена контракта и исполнение не определяются по факту нахождения извещения.

ПРОВЕРКИ
Проверки выполнены в Linux/Chromium. Нативное окно и установщик Windows здесь не проверены.
Живой доступ к ЕИС в облачной среде был заблокирован сетевой политикой; сетевые сценарии проверены
на контролируемых ответах, с настоящими API, SQLite, документами и движком разбора ТЗ.
Подробные результаты — QA_REPORT_4_0_39.md.
