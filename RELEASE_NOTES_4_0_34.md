# QX Подборщик 4.0.34 — Тендерный отдел и календарь

## Что изменилось
- При загрузке ТЗ привязка к реестру **выключена по умолчанию**. Пользователь самостоятельно включает галочку и указывает номер извещения ЕИС: 19/20 цифр (44-ФЗ) или 11 цифр (223-ФЗ).
- Можно привязать к закупке ранее загруженное ТЗ, не создавая новый расчёт. Несколько проектов могут ссылаться на одну закупку; изменение номера обновляет соответствующую привязку и себестоимость обеих карточек.
- Запрос общедоступной XML-карточки ЕИС по точному номеру (19/20 цифр). При доступности: название закупки, заказчик, НМЦК, дата и местное время окончания подачи. При блокировке сайта: ручной ввод. Данные не выдумываются.
- Появилось поле «Приём заявок до (время местное)»; миграция SQLite 4 → 5 создаёт защитный снимок базы до изменения.
- Календарь: месяцы, выбор дня, фильтры «Подача заявок», «Аукцион», «Поставка», «Оплата», панель событий. Даты берутся из сохранённых карточек.
- Реестр и «Контракты и поставки»: исправлены переносы длинных номеров и описаний, отображаются сроки подачи.
- Ускорен локальный AI Lite: для извлечения требований из ТЗ уменьшен лимит генерации JSON с 370 до 280 токенов. Скорость реального ответа зависит от CPU/модели; обещания мгновенного распознавания нет.

## Ограничения
ЕИС — публичная попытка чтения XML без авторизованного API. XML может быть недоступен или содержать неоднозначные поля. Значения должны быть проверены перед подачей заявки. 11-значные закупки привязываются вручную, их XML-запрос не производится.

Не проверено на Windows / WebView2 с реальным подключением к ЕИС и моделью Qwen. Существующие пользовательские БД и AI-модели обновление не заменяет.
