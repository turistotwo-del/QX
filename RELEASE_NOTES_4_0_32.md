# QX 4.0.32 — исправление QX AI Lite

- Ограничен вывод маленькой модели: максимум 2 предложения за один ответ.
- Для llama.cpp включено структурированное формирование JSON, если версия сервера это поддерживает; при ответе 400/404/422 fallback на старый режим.
- При обрыве JSON программа не дописывает несуществующие значения: извлекает только полностью закрытые предложения, проводит прежнюю проверку точных цитат и типов значений.
- Если полных предложений нет, ровно одна короткая повторная попытка; при повторном обрыве — понятное предупреждение без автозаполнения.
- Исправлена разметка двух переключателей QX AI в светлой и тёмной теме (вместо больших пустых квадратов обычные checkbox).
- Никакие базы закупок, прайсы, сохранённые расчёты, модели GGUF и Python не входят в QuickFix.
- **Ограничения:** Windows и реальная Qwen2.5 1.5B здесь не запускались; AI-ответы в E2E имитированы. Реальный успешный разбор конкретного ТЗ на пользовательском CPU не гарантируется. Самотест self_test.py существовавшей версии 4.0.31 имеет отдельный падaющий assert DDR4, который не входит в выпуск этого исправления.
