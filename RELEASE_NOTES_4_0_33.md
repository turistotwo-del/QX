# QX Подборщик 4.0.33 — сохранение и экспорт (тестовая сборка)

## Причина
В modern/native_bridge.py функция file_dialog() импортировала tkinter, которого нет
в python-3.12.x-embeddable-amd64.zip. Поэтому «Сохранить», «Заполнить DOCX»,
«Скачать XLSX» и другие операции завершались ModuleNotFoundError.

## Изменения
- Независимый системный диалог Windows через встроенный PowerShell 5.1 + .NET Windows Forms
  в отдельном STA-процессе — никаких tkinter, pip, администраторских прав или сети.
- Двоичная передача выбранного пути в UTF-8/Base64 (кириллические имена путей).
- Если системное окно недоступно, фронтенд пытается скачать экспорт браузерным
  способом; при отмене не показывает ложное «Сохранено».
- Сохранили атомарную запись (временный файл, затем замена).
- Для открытия ТЗ .odt в native file picker исправлен список расширений.
- Существующие проекты, тендеры, пользовательские каталоги и QX AI не меняются.

## Проверки
337 тестов pytest, в том числе новые регрессии на 5 экспортных расширений;
браузерные сценарии запуска, нескольких ТЗ, сохранения через WebView Bridge, отмены
и запасного скачивания в Chromium прошли. Настоящий Windows WebView2 и
PowerShell диалоги в данной среде не запускаются — необходима проверка на Windows.
