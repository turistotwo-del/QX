QX Подборщик 4.0.29 — исправление установки окна

Причина сбоя из лога:
  NameError: name 'webview' is not defined
    из-за обработки аргументов Python -c в Windows PowerShell 5.1.
  ERROR: no matching distributions for proxy-tools
    из-за параметра pip --only-binary=:all:.
  proxy-tools 0.1.0 на PyPI распространяется только архивом исходного кода.

Исправления:
- Проверка import webview / import clr вынесена в portable\desktop_probe.py.
- Установка оконных компонентов использует pip --prefer-binary и разрешает
  собрать маленькую исходную библиотеку proxy-tools. Это НЕ установка
  системного Python и НЕ повторная установка QX AI.
- Повторная проверка pywebview производится при каждом старте; частично
  установленный модуль не выдаётся за исправный.
- Папка с моделью AI, закупки, проекты, цены и существующий .qx_runtime
  сохраняются.
- Фирменный значок и ярлыки QX из версии 4.0.28 сохранены.

УСТАНОВКА ПОВЕРХ РАБОЧЕЙ QX:
1. Полностью закрой QX, включая окно терминала.
2. В архиве обновления открой ОБНОВЛЕНИЕ_В_ПАПКУ_QX.
3. Скопируй её СОДЕРЖИМОЕ в свою папку QX, где ЗАПУСТИТЬ_QX.cmd,
   согласившись на замену файлов.
4. Запусти ЗАПУСТИТЬ_QX.cmd при наличии интернета.

НЕ УДАЛЯЙ .qx_runtime, базу в AppData, папку QX_AI!
Если после этого установка не заработает, пришли новый текст ошибки.

ОГРАНИЧЕНИЕ: на реальной Windows эта версия пока не запущена автором;
проверены исходники и доступные автоматические тесты в Linux.
