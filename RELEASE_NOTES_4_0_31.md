# QX Подборщик 4.0.31 — Advanced TZ Formats & AI Auto-fill

- Сохранён весь функционал версии 4.0.30 и локальный QX AI Lite 1.5B.
- Расширен разбор DOCX с изменённым порядком столбцов характеристик.
- XLSX/XLSM: несколько листов и позиции в одной закупочной спецификации, раздельные количества.
- Текстовые ТЗ: `параметр: значение`, `параметр — значение`, `Позиция № N`.
- Базовая обработка текстовых ODT без внешнего офисного пакета.
- AI Lite выбирает значимые строки из разных мест ТЗ, сократил ответ с 560 до 370 токенов.
- `Проверить все позиции`: последовательный не блокирующий интерфейс анализ нескольких ТЗ.
- При включённой опции пустые числовые поля с однозначной цитатой заполняются автоматически. Уже заполненные/спорные значения остаются на ручную проверку.
- Документы из разных позиций не смешиваются, цитаты сверяются с исходным блоком.
- Важно: не заявляем 100% точность. OCR для сканированного PDF и старые бинарные DOC/XLS не встроены.
- Совместимо с сохранённым Python, QX AI, данными и проектами из 4.0.30.
