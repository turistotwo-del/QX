# QX Подборщик 4.0.24 — кандидат Windows Portable

**Статус: кандидат для пользовательского тестирования; не сертифицированный Windows-релиз.**

## Функции

- Сохранён классический движок подбора и расчёта QX, обработка ТЗ и экспорт документов.
- Отдельный «Тендерный отдел»: реестр, календарь, контракты, поставки, финансы, напоминания, организации.
- Документы DOCX/PDF/XLSX/XML, безопасный импорт ZIP, загрузка по прямым официальным HTTPS-ссылкам на файлы ЕИС (до 10 за операцию), локальный анализ с источниками.
- **Новое:** экспорт Word-отчёта из карточки закупки. Источники, найденные условия, реестровый BIOS, непрочитанные документы, подтверждённые предложения. Без изменения записи в базе.
- **Новое:** «ЗАПУСТИТЬ_QX.cmd» + `portable/start_qx.ps1` — создание собственного runtime Python 3.12.10 в каталоге QX без прав администратора. SHA-256 Python сверяется с официальным манифестом Python.org. Требуется интернет на первом запуске.
- Все пользовательские цены/настройки и архивы сохраняются вне папки запуска при использовании нового сценария запуска.

## Что проверено в Linux/Chromium

- 241 автоматический тест тендерной части, включая 6 новых тестов отчёта и сценария запуска.
- 27 тестов прежнего подборщика QX.
- Проверка приложения `--selfcheck`, реального HTTP-сервера и TypeScript.
- Браузерные сценарии: ТЗ → закупка → расчёт → заполнение; автономный поиск AI; GGUF-интерфейс; перенос QX 3.3.7.

## Что НЕ проверено / не реализовано

- Этот архив НЕ содержит собранный Windows EXE. Загрузка Python/библиотек и запуск через PowerShell на Windows не прогонялись в текущей Linux-среде.
- Модель Qwen GGUF не вложена и не испытана в Windows-пакете. Выдержки по документам доступны без неё.
- Нет подтверждённой автоматической массовой выгрузки документации по номеру через официальный СОИ ЕИС. Живая выдача RSS/прямых ссылок может быть недоступна.
- Выводы о соответствии требованиям/реестрам должны проверяться человеком по первоисточнику.

## Для диагностики

При неполной первой загрузке повторите запуск с интернетом. Если runtime стал нерабочим, удалите **только** `.qx_runtime` внутри извлечённой папки QX и повторите загрузку. Это не удалит базу закупок в `%LOCALAPPDATA%`.
