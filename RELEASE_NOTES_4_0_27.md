# QX Подборщик 4.0.27 — QX AI Lite (development)

## Изменения

- Вместо тяжёлой Ollama + Qwen3 4B автоматически устанавливается компактный CPU-движок llama.cpp и русскоязычная Qwen2.5 1.5B Instruct Q4_K_M. Общая ориентировочная занятость AI — 1,2–1,5 ГБ, для установки потребуется дополнительно свободное место под временные файлы (скрипт проверяет около 2,5 ГБ). Точные размеры зависят от версии скачанного CPU-архива.
- Старая Ollama и скачанные ранее модели **не удаляются** и не модифицируются; при необходимости освобождать место нужно вручную.
- QX автоматически запускает AI Lite при открытии программы и останавливает лишь созданный им процесс при закрытии. Всё слушает **127.0.0.1:11435**.
- Вопросы по контрактам и краткие ответы с местом в документе; проверка ТЗ — через JSON-предложения с дословными цитатами и ручным подтверждением перед пересчётом.
- Можно использовать старую Ollama, если QX Lite не установлен. Ручная загрузка документов ЕИС без изменений. Несколько ТЗ сохраняются.
- При отсутствии интернета или неудачной загрузке основной подбор доступен, установку AI можно повторить файлом «УСТАНОВИТЬ_QX_AI.cmd».

## Ограничения

- Небольшая модель иногда пропускает требования, неправильно трактует отрицания и длинные пункты. Предложения AI **не принимаются автоматически**: проверяйте цитаты и числовые значения.
- Для сложных многостраничных ТЗ используется ограниченный контекст (предупреждение в интерфейсе). Сценарий реальной загрузки и запуска AI на Windows **в этой среде не проверен**, поэтому версия тестовая.
- Первый запуск QX Portable по-прежнему требует установки Python-зависимостей (они не включены в размер AI).
- Движок загружается с релиза ggml-org/llama.cpp, контрольная сумма берётся из официальной GitHub release API. Модель скачивается с официального Hugging Face Qwen; проверяются GGUF-формат и размер, но SHA-256 этой модели пока не фиксируется.

Источники: https://github.com/ggml-org/llama.cpp/releases ; https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF
