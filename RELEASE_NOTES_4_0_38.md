# QX Подборщик 4.0.38 — ЕИС, сохранение проектов, этапы поставок

Тестовая portable-сборка. Требует предварительно установленного QX 4.0.37 для маленького обновления. Создана для проверки на Windows; реальная загрузка ЕИС не проверялась в данном окружении.

## Функции

- **Документы закупки:** новая команда «Найти документы» ищет публичные ссылки на официальных страницах ЕИС по точному номеру извещения. Показывает предварительный список файлов, их подписи и ссылку на официальный поиск. Команда «Скачать найденные» загружает найденное (не более десяти файлов за раз) в документы выбранной закупки. Страницы HTML, капчи, редиректы на сторонние домены, превышение размера и невалидные документы отклоняются. Результат и ошибки видны в интерфейсе. Контрактные поля не меняются при загрузке автоматически. Поиск по ЕИС — best effort, не гарантирован: портал может не предоставить ссылки и может потребовать ручной вход. Для документов, отсутствующих в публичной карточке извещения, сохранена ручная загрузка.
- **Новый расчёт:** если активная работа не сохранена в `.qxproj` либо после сохранения она менялась, QX показывает предупреждение. Действия: отменить, сохранить `.qxproj` и создать новый, создать без сохранения. Автосохранение не выдаётся за отдельную экспортированную копию.
- **Поставки:** более понятные карточки этапов (название партии, количество, крайний срок, статус). Удаление отдельного этапа с подтверждением; история фиксирует событие. Остальные этапы, карточка закупки, заметки и база оборудования не удаляются.

## Безопасность и ограничения

- Сетевой поиск ограничен официальным HTTPS-доменом `zakupki.gov.ru` и публичными страницами ЕИС, никаких сторонних сайтов автоматически не обходится.
- QX не обходит авторизацию или капчу и не делает заключений о статусе контракта на основе ссылки.
- Скачанные файлы подлежат формальной проверке; если файл является сканом PDF, может потребоваться OCR.
- Установленная QX AI, цена оборудования, файлы `.qxproj` и локальные SQLite пользователя не изменяются патчем.
- При резервном браузерном скачивании `.qxproj` приложение может не знать, закончилось ли системное сохранение; наличие файла стоит проверить вручную.

## Испытания

- 90 регрессионных тестов (10 субтестов) — пройдены.
- 24 дополнительных проверки совместимости — пройдены.
- Отдельная проверка диалога несохранённого расчёта в Chromium — подтверждена; полный браузерный набор не завершился из-за зависания Chromium.
- Не проверено на настоящей Windows с реальной доступностью ЕИС.
