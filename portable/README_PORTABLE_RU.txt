QX Подборщик 4.0.35 — переносной запуск (кандидат, не сертифицированный Windows-релиз)

1. Распакуйте весь ZIP в обычную папку, например C:\QX_4_Portable.
   Не запускайте файлы непосредственно внутри ZIP. Не помещайте папку в Program Files.
2. Дважды щёлкните «ЗАПУСТИТЬ_QX.cmd».
3. При ПЕРВОМ запуске нужен интернет: будут скачаны только в папку QX:
   - официальный Python 3.12.10 Windows x64 с сайта python.org (SHA-256 проверяется);
   - pip с bootstrap.pypa.io;
   - Python-библиотеки из PyPI.
   Установка Python в систему не выполняется, права администратора не требуются.
4. В дальнейшем исходные расчёты, проверка документов и поиск фрагментов могут
   выполняться офлайн. Курсы валют не обновляются без интернета.
5. QX откроется в собственном окне через pywebview / Microsoft Edge WebView2.
   Режим обычного Edge отключён, чтобы не было ошибки 127.0.0.1 и чужого значка.
   Если WebView2 отсутствует, установите Microsoft Edge WebView2 Runtime.

Данные закупок и вложения сохраняются в %LOCALAPPDATA%\QXPodborshchik,
прайсы и настройки — в пользовательских папках QX. Их нельзя удалять при
очистке кэша. Сделайте копию рабочих данных до первого тестирования.

Ограничения: этот Windows-режим НЕ запускался и не проверялся на настоящей
Windows в среде разработки. Он зависит от первого сетевого скачивания.
В ZIP нет заранее скачанных AI-бинарников и модели; они устанавливаются при первом запуске и не подключён официальный СОИ ЕИС.
По ЕИС есть ручная загрузка документов, ZIP-пакетов и прямых HTTPS-ссылок,
но получение всей документации автоматически по номеру не гарантируется.

Вкладка тендера -> «Отчёт Word» формирует DOCX с источниками и предупреждениями.

Если запуск не удался, текст ошибки будет показан в консольном окне. Можно
удалить ТОЛЬКО папку .qx_runtime и повторить запуск с интернетом, не затрагивая
базы и документы в пользовательском профиле.

НЕСКОЛЬКО ТЗ И АНАЛИЗ ДОКУМЕНТОВ (с 4.0.25):
- Во вкладке «Загрузка ТЗ» можно одновременно выбрать до 12 файлов;
  добавление документов не удаляет вручную заданные цены и комплектации.
- Для заполнения Word-заявки выберите позицию и исходное ТЗ.
- ЕИС: файлы загружаются вручную, автоматический импорт не обязателен.

НОВОЕ В 4.0.27 — QX AI LITE:
- При первом запуске QX самостоятельно устанавливает локальный CPU-движок llama.cpp
  и Qwen2.5 1.5B Instruct Q4_K_M (модель около 1,1 ГБ).
- AI в целом ориентировочно занимает 1,2–1,5 ГБ; нужно примерно 2,5 ГБ
  свободного места на время загрузки и распаковки.
- Нейросеть помогает найти в контракте суммы, даты, условия оплаты и поставки,
  а также предлагает исправления в распознанном ТЗ с цитатами из источника.
- Исправления применяются только после подтверждения пользователем.
- При ошибке скачивания QX продолжает работать без AI. Повторить установку:
  «УСТАНОВИТЬ_QX_AI.cmd»; лог: QX_AI\logs\setup-lite.log.
- AI работает локально и не отправляет содержание документов сторонним API.
- Если старая Ollama была установлена в 4.0.26, она не удаляется автоматически
  и продолжает занимать место; освобождать его нужно отдельно, осторожно.

ПОЛНОЕ ОПИСАНИЕ И ОГРАНИЧЕНИЯ: RELEASE_NOTES_4_0_27.md.

HOTFIX 4.0.27.1 — запуск Windows Portable:
- Исправлен путь модулей Python: первая установка ранее могла завершаться
  ModuleNotFoundError: No module named 'modern'.
- В повторном запуске уже скачанный Python и библиотеки сначала проверяются,
  повторное скачивание не требуется, если самопроверка проходит.
- Чтобы починить уже распакованную установку, замените только
  portable\start_qx.ps1 из этой сборки и снова запустите ЗАПУСТИТЬ_QX.cmd.

ОБНОВЛЕНИЕ 4.0.28: отдельное нативное окно QX, ярлык на столе и в Пуск с логотипом.

HOTFIX 4.0.29 — зависимость proxy-tools и проверка pywebview:
- Исправлена команда Python -c, некорректно передававшая кавычки через PowerShell.
- proxy-tools распространяется только в исходном коде; при установке оконного
  компонента используется --prefer-binary, а не --only-binary.
- Поверх 4.0.28 не удаляйте .qx_runtime и QX_AI: установка переиспользует их.


QX 4.0.30: QX AI Lite получил уменьшенный контекст и быстрый тест генерации (раздел «Загрузка ТЗ» → «Тест ответа AI»). При долгих документах анализ неполный, смотрите предупреждения и сверяйте исходники. Обновление не требует скачивать модель повторно.


QX 4.0.31: расширено понимание форматов ТЗ (колонки таблиц КТРУ в другом порядке, несколько
листов Excel, спецификации с несколькими товарными строками, текстовые пары «параметр: значение»,
ODT). Добавлены AI-анализ всех позиций, быстрый поиск релевантных фрагментов по документу и
безопасное автоматическое заполнение ТОЛЬКО пустых числовых полей при однозначной цитате.
AI не заменяет профессиональную проверку: спорные значения и изменения заполненных полей
требуют ручного подтверждения. Сканированные PDF без текстового слоя требуют OCR вне QX.
Модель остаётся прежней, повторно скачивать её при обновлении не требуется.

QX 4.0.32: AI Lite теперь использует JSON-режим при поддержке движка, короткий ответ, однократную компактную повторную попытку при обрыве JSON и принимает только полностью закрытые, подтверждённые цитатой предложения. Восстановлено нормальное отображение переключателей QX AI.

QX 4.0.33: ИСПРАВЛЕНЫ СОХРАНЕНИЕ И ВЫБОР ФАЙЛОВ В СОВРЕМЕННОМ ОКНЕ.
Windows Portable Python не содержит tkinter. Теперь приложение использует стандартные
окна Windows (PowerShell 5.1 / Windows Forms, STA) без дополнительных Python-библиотек.
Если Windows блокирует системный диалог, для экспорта запускается обычная загрузка
файла браузерным движком WebView2. Проверьте папку «Загрузки»; скачивание не означает
автоматического сохранения в ранее выбранную папку.
Поддерживаются: проект .qxproj, Excel .xlsx, заявка/КП .docx, база .qxdb, копии .zip.
Открытие файлов также работает без tkinter. Существующие данные не удаляются.

QX 4.0.34: привязка ТЗ к закупке только по галочке, ручной номер ЕИС,
публичный XML ЕИС при доступности, крайний срок подачи с временем,
календарь событий и улучшенное форматирование тендерных таблиц.
Сайт ЕИС может блокировать автоматические запросы; в этом случае заполните поля вручную.

QX 4.0.35: «Быстрые заметки» в левой панели. Автосохранение,
поручения, сроки, поиск, выполнение, закрепление, копия JSON.
Записи хранятся в локальной базе QXPodborshchik/quick_notes.sqlite3
(обычная резервная копия тендеров не включает эту отдельную базу).


HOTFIX 4.0.36.1 — установка pywebview на втором компьютере:
- При первом запуске QX устанавливает setuptools и wheel только в свою
  папку .qx_runtime\python\Lib\site-packages.
- Зависимость proxy-tools собирается с флагом --no-build-isolation: это
  устраняет `BackendUnavailable: Cannot import setuptools.build_meta`
  из-за изолированного Python, используемого portable-сборкой.
- Удалять .qx_runtime и заново скачивать модель QX AI НЕ нужно.
- Если загрузка PyPI недоступна, попробуйте снова при наличии интернета.
- QX использует системный Edge WebView2 Runtime. Если не найден WebView2,
  потребуется установить WebView2 Runtime от Microsoft.
