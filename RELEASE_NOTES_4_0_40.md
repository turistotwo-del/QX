# QX 4.0.40 (development)

Карточка закупки теперь сохраняется сразу. Запрос сайта выполняется фоном, показывает этапы,
сохраняет частичный результат и не скрывает карточку при отказе источника или отсутствии библиотеки.

Исправлены:

- Единая HTTP-сессия с cookies для поиска ЕИС, карточки и документов.
- Реальная вкладка документов, ссылки 223-ФЗ по ID, `file.html?uid`, XML-вложения и XML внутри `<pre>`.
- Приоритет `filename*`, кодировки имени и определение формата файла по содержимому при непрозрачной ссылке.
- Дополнительные реальные поля XML и HTML, включая цену и окончание подачи.
- Обработка HTTP-ошибок, незавершённых ответов и частичных скачиваний.
- Проверка компонентов ЕИС при каждом Portable-запуске; старый ready-маркер больше не скрывает отсутствие библиотек.

Добавлены:

- Контур.Закупки как вторичный публичный источник по точному номеру, с явным происхождением сведений.
- Фоновая очередь с ограничением параллелизма; повторные клики используют текущую задачу.
- Восстановление отображения задачи после перезагрузки страницы.
- Ввод номера с `№`, пробелами и ссылкой ЕИС; ведущие нули сохраняются.
- Сохранение RAR/7z оригиналами без распаковки и исполнения.
- Отображение запущенной версии и запрет кэширования файлов интерфейса.

Интерфейс и существующие расчёты сохранены. Ручные значения не заменяются автоматически.
Живая доступность сайтов и нативный запуск Windows остаются непроверенными в этой облачной среде.
