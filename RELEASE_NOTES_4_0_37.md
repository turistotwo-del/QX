# QX Подборщик 4.0.37 — календарь задач и котировки

Разработка поверх QX 4.0.36.1; тестовая Windows portable-сборка.

## Новый календарь
- Заметки с полем «Выполнить до» отображаются во вкладке «Тендерный отдел → Календарь и задачи».
- Задача открывает исходную заметку и изменяется через тот же редактор; выполненные заметки отмечены.
- В блокноте при наличии срока доступна кнопка перехода на этот день календаря.
- Невыполненные поручения включены в общий список «Сроки и напоминания» и в включённые Windows-уведомления. Оповещения срабатывают лишь при работающем QX.
- Записи остаются в отдельной пользовательской quick_notes.sqlite3, дублирования задач в базе закупок нет.

## Запрос котировок
- В карточке закупки на вкладке «Обзор» — галочка «Запрос котировок — без аукциона и торгов».
- Для котировок вместо полей аукциона показываются дата и необязательное время подведения итогов.
- Календарь/напоминания не показывают аукцион для котировок, даже если его дата раньше была в записи.
- Сохраняются срок подачи заявок и отдельная дата итогов; даты не вычисляются из других полей автоматически.
- Данные прошлых закупок не сбрасываются: миграция SQLite v6 → v7 создаёт резервный снимок прежней базы до обновления.

## Установка
Закрыть QX, сохранить резервную копию, распаковать маленький ZIP, скопировать содержимое ОБНОВЛЕНИЕ_В_ПАПКУ_QX в уже установленную папку QX с заменой. Не удалять .qx_runtime и каталоги пользовательских данных. При обновлении установки Python и AI не требуется.

## Ограничения
Работа нового интерфейса проверена в Chromium на Linux с тестовым API; сборка не проходила фактический запуск на Windows. Сроки и время итогов пользователь задаёт вручную. Уведомления Windows требуют включённой опции и запущенного приложения.
