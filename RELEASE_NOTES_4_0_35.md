# QX Подборщик 4.0.35 — быстрые заметки

Обновление поверх 4.0.34. Не затрагивает данные закупок, расчётов, каталогов или установленную локальную модель QX AI.

## Блокнот в левой панели

- Новая вкладка **«Быстрые заметки»** в рабочей области под «Документы».
- Нажатие **«Новая заметка»** создаёт запись немедленно, даже без текста; можно сразу писать информацию во время звонка.
- Поля: заголовок, источник («Звонок», «Поручение босса», «Встреча», «Переписка», «Личная запись»), необязательный срок, полный текст.
- Автоматическое сохранение при печати и при выходе из поля. Состояние сохранения видно под редактором.
- Закрепление, отметка выполнения, поиск, показ завершённых записей, удаление с подтверждением.
- Кнопка **«Копия заметок»** — сохранение читаемого JSON-файла через существующий механизм сохранения QX.

## Хранение

Заметки сохраняются в собственной SQLite-базе `quick_notes.sqlite3` в пользовательской директории QX (обычно `%LOCALAPPDATA%\QXPodborshchik`). Они не привязаны к отдельному проекту `.qxproj` и остаются после обновления файлов программы. Обычный ZIP-бэкап тендеров **не содержит** отдельную базу заметок: для резервной копии пользуйтесь кнопкой «Копия заметок» либо копируйте `quick_notes.sqlite3` при закрытой программе.

## Примечания

- Экспорт JSON позволяет сохранить копию заметок; **обратный импорт JSON пока не реализован**.
- Срок заметки отображается в списке («Сегодня», «Просрочено»), но не создаёт системные Windows-уведомления или событие календаря закупок.
- Запуск в реальной среде Windows/WebView2 требуется проверить на пользовательском ПК.
