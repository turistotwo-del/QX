# Проверки QX 4.0.35

- Python API SQLite заметок: создание, чтение, обновление, устойчивость к запоздавшим запросам, проверки ввода, удаление, JSON-экспорт — 4 теста, пройдены.
- Общие регрессионные тесты: **348 пройдены**, 25 subtests пройдены; предупреждения касаются DeprecationWarning старых внешних зависимостей и SyntaxWarning в прежнем тесте.
- TypeScript→JavaScript (`tsc`) и `node --check` — без ошибок.
- Chromium E2E: создание записи, сохранение после немедленного ухода из раздела, повторное открытие после нового контекста страницы, поиск, закрепление, завершение, удаление — пройдено.
- Обновление использует отдельно выделенную базу SQLite для заметок, без изменения таблиц закупок.

Ограничения: на настоящей Windows не проверены первый запуск нового архива и системный диалог экспорта. Уведомления Windows по срокам заметок не добавлялись.
